# enzoxmotion UGC System v2

This package is a practical creator system for turning proven ad ideas into repeatable UGC and slideshow batches.

## What's inside
- SYSTEM.md — core operating rules
- HOOK_LIBRARY.md — reusable hook structures and examples
- FORMATS.md — ready-to-use UGC + slideshow structures
- BATCHING.md — how to turn one idea into a full testing batch
- CREATOR_SCALING.md — when and how to move from one creator to a campaign
- CREATOR_BRIEF_TEMPLATE.md — a copy-ready creator campaign brief

## Fast start
1. Add this folder/ZIP to GPT or Claude as reference material.
2. Give it your product, audience, platform, and one or more reference ads.
3. Ask it to build a batch using the formats and hooks inside this package.
4. Test the batch before scaling creator volume.
5. When one or more angles prove themselves, use the creator scaling playbook.
