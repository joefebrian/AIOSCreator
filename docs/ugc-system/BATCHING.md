# Creative Batching System

The purpose of batching is to learn quickly without turning production into random variation spam.

## Batch 0 — Extract the control
Define:
- core angle
- hook type
- first-frame visual
- creator style
- product reveal point
- CTA
- length

Write down why you think it works. This becomes the hypothesis.

## Batch 1 — Hook test
Keep almost everything else stable. Create 6–10 versions where the main change is the hook.

Example split:
- 2 pain-first
- 2 proof-first
- 2 curiosity
- 2 outcome

Purpose: learn what gets the viewer into the body of the ad.

## Batch 2 — Presentation test
Take the strongest hook/angle and change how it is presented:
- talking head
- screen recording
- slideshow
- POV/demo
- comment reply
- comparison

Purpose: find the native format with the best retention + conversion fit.

## Batch 3 — Angle test
Keep the product and audience stable, but change the reason to care:
- save time
- save money
- reduce frustration
- better result/quality
- social/status benefit
- beginner-friendly
- advanced/pro workflow
- novelty/discovery

## Batch 4 — Scale pack
Once an angle + format has signal, create 20–50 executions by combining proven variables:
- 5 hooks
- 3 opening visuals
- 2 creator deliveries
- 2 CTAs
- multiple creator faces/accounts if available

Do not force every mathematical combination. Remove combinations that feel unnatural.

## Production board
Track:
- ID
- creator
- angle
- hook
- format
- first frame
- length
- CTA
- post date
- views
- retention/hold if available
- clicks/conversions if available
- cost
- notes

## What to keep stable
When testing one variable, keep these as stable as possible:
- offer
- landing page
- audience
- creator type
- product demonstration
- general duration

## When to kill a concept
Do not kill an entire angle from one weak execution. First ask whether the failure came from:
- weak first frame
- weak hook
- slow reveal
- unclear product
- poor creator delivery
- bad platform fit

Kill an angle after multiple competent executions fail to create useful signal.

## When to expand a concept
Expand when at least one is true:
- the post clearly beats the creator/account baseline
- retention/hold is materially stronger
- comments show repeated product curiosity
- clicks or conversions are strong
- multiple independent executions around the same angle work

The stronger the downstream conversion data, the less you should rely on views alone.
