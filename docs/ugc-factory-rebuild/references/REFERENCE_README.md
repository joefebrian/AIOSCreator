# Reference bundle

This folder contains the original Yapping Creative Bible v1.0 and Astra implementation guide read for this handoff.

They provide creative/reference integration guidance. They are not a new trained model, a category-sales dataset, or the user's visual benchmark video.

The full 75-source corpus, individual reports/transcripts, raw media evidence, and resolver are separate existing deliverables. Reuse them through their actual repository/media locations when needed. Do not invent those files or resolve their relative links to unrelated assets.

Use abstract guidance when the raw corpus is unavailable or not runtime-approved. Preserve attributed source claims and existing runtime/editorial flags when the corpus is present.

The user's designated benchmark video must be available to the implementing builder and recorded by actual file/media identity. No benchmark video is included in this text-focused handoff archive.
